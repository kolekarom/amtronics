## 🌟 Overview

AmTronics is a cutting-edge PCB assembly service provider offering end-to-end solutions for all your electronic manufacturing needs. From prototype to production, we ensure high-quality PCB assembly services with quick turnaround times and competitive pricing.

## 🚀 Features

- **High-Quality PCB Assembly**
- **Rapid Prototyping**
- **Component Sourcing**
- **Surface Mount Technology (SMT)**
- **Through-Hole Assembly**
- **Testing & Quality Assurance**
- **Low to High Volume Production**

## 🔧 Technologies Used

- **Frontend**: Next.js, React, TypeScript
- **Styling**: Tailwind CSS
- **Deployment**: Vercel
- **Form Handling**: React Hook Form
- **UI Components**: Shadcn/UI
- **Icons**: Lucide Icons

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or later)
- npm (v9 or later) or yarn
- Git

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/kolekarom/amtronics.git
   cd amtronics
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

3. Start the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
